2. Đối chiếu 5 đặc tính điện toán đám mây theo NIST

  • Tự phục vụ theo yêu cầu (On-demand self-service): Tự khởi tạo môi trường máy ảo lập trình chỉ qua nút "Create codespace" mà không cần admin duyệt hay can thiệp thủ công.
  • Truy cập mạng rộng (Broad network access): Lập trình trên trình duyệt web và gọi API từ điện thoại di động qua mạng Internet thông thường.
  • Gộp tài nguyên (Resource pooling): Máy ảo Codespace được trích xuất từ cụm máy chủ dùng chung của GitHub/Azure phục vụ nhiều người dùng đồng thời.
  • Co giãn nhanh (Rapid elasticity): Máy ảo được tạo mới, mở rộng hoặc thu hồi tài nguyên ngay lập tức khi người dùng Start hoặc Stop codespace.
  • Dịch vụ đo lường được (Measured service): Hệ thống theo dõi chính xác từng core-giờ hoạt động được thống kê chi tiết trong trang GitHub Billing.
